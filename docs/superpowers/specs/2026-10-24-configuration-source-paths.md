# Configuration 来源身份

## 问题与选择

Configuration 合并结果允许任意字符串键，但来源索引把层级拼为点分字符串。字面键 `a.b` 和嵌套 `a → b` 共享索引；用标量替换映射 `a` 时，前缀删除还会误删字面键的来源。这使 `--show-config` 的来源与实际配置不一致。

使用 [RFC 6901](https://www.rfc-editor.org/rfc/rfc6901) JSON Pointer 表达 `sources["fields"]` 的键。每层以 `/` 分隔；token 内 `~` 编为 `~0`，`/` 编为 `~1`。字面点不转义，空键使用 `/`。只生成指针，不增加求值器或依赖。来源值仍为文件路径，不含配置值。

拒绝含点的合法键会人为限制宿主数据；自定义点转义会新增不必要的语法。采用标准指针统一迁移，不保留点分别名或旧格式选择。

## 不变量与职责

- 合并、来源相对路径、数组替换、false/nil/缺失、空映射合并语义保持不变。
- 来源索引的叶子/祖先替换必须与实际合并一致；兄弟字面键不能被前缀删除。
- 数组是整体替换值，在数组字段指针上记录来源，不逐元素建表；空映射作为值时也记录其字段。
- `path_fields` 是宿主声明路径字段的既有语法，和来源输出不同，不在此阶段改变。
- 库保持 Ruby >= 3.4，不依赖 Runner/Parser/connector；lib 方法说明中文、业务字面量英文。
- VXLAN/Wireless/connector 仍透传来源结构；其领域校验、命令、状态与资源所有权不迁移。
- 保留所有既有 WIP 和当前依赖政策，不提交、推送或发布。

## 范围

11 个文件：ctx_cli 的 configuration.rb、configuration_spec.rb、README、migration、Changelog、本规格及计划；VXLAN/Wireless 各一个参数来源测试；connector 的 config_test 和 cli_setup_test。没有新增配置项或生产适配器。

## 验收

回归从真实 YAML 层证明字面点与层级不同、slash/tilde/空键/Unicode 不碰撞、替换映射只删除真正后代、数组整体替换、冻结及不含秘密值。先观察旧实现失败，再修改来源键构造与后代前缀。迁移消费端断言后运行四模块 gates、实际入口和精确候选普通/Bundler 安装。使用既有 500/1000/3000 字段基准检查规模趋势，不为共享主机设硬性能阈值。一次独立审查，无双格式接口。
